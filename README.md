# Hi, I'm Yazan

I build developer tools that improve configuration, testing, debugging, observability, and scaffolding workflows.

## Developer Tools Portfolio

- [Config Playground](https://github.com/anxiouscrypt/config-playground): live JSON configuration editing with multi-tenant app preview, validation, and SQLite persistence.
- [API Mock Server Generator](https://github.com/anxiouscrypt/api-mock-server-generator): define mock endpoints, serve configured responses, test requests, and inspect logs.
- [Local Dev Dashboard](https://github.com/anxiouscrypt/local-dev-dashboard): monitor local service health, ports, response times, history, and event logs.
- [Request Replay Tool](https://github.com/anxiouscrypt/request-replay-tool): capture proxied HTTP requests, inspect responses, and replay original or edited payloads.
- [Rule-Based Dev Assistant](https://github.com/anxiouscrypt/rule-based-dev-assistant): no-API command palette that generates common engineering snippets through deterministic rules.

The common thread: small tools that reduce friction in the software development workflow.
