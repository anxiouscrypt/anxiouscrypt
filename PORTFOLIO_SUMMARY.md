# Developer Tools Portfolio Summary

## Narrative

I build small developer tools that reduce friction in software development workflows: configuration, mocking APIs, local environment monitoring, request debugging, and rule-based assistant workflows.

## Projects

### Config Playground

Live JSON configuration playground for previewing multi-tenant app behavior without code changes.

Proves: config-driven architecture, schema validation, frontend/backend integration, and product-minded SaaS tooling.

### API Mock Server Generator

Tool for defining mock endpoints and returning configured JSON responses through runtime routes.

Proves: API design, route matching, request logging, and developer productivity thinking.

### Local Dev Dashboard

Dashboard for tracking local service health, ports, response time, and recent status history.

Proves: observability fundamentals, local tooling, and multi-service development awareness.

### Request Replay Tool

Local proxy that captures, stores, inspects, edits, and replays API requests.

Proves: HTTP fundamentals, debugging workflows, persistence, and replayable API testing.

### Rule-Based Dev Assistant

Frontend-only assistant-style command palette that generates engineering snippets without a paid AI API.

Proves: deterministic rule systems, template rendering, command palette UX, and AI-adjacent product thinking.
